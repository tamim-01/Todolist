# Todo List Application (Full Stack)

**Authors**: This project was created by **Tamim Yousefi** and **Sepehr Sharafi**.

---

## **Overview**

This is a full-stack Todo List application that includes both the **backend** and **frontend** components. The backend is built using **[Node.js/Express]**, while the frontend is built using **[React]**. The application provides a user-friendly interface for managing tasks, user profiles, and more.

---

## **Features**

### **Backend Features**
- ✅ User registration and login
- ✅ Task management (create, read, update, delete tasks)
- ✅ Profile management with avatar support
- ✅ RESTful API with multiple routes for application management
- ✅ Docker support for easy deployment

### **Frontend Features**
- ✅ User login and signup
- ✅ Task management (add, update, delete tasks)
- ✅ Profile management with avatar support
- ✅ Responsive design for various devices

---

## **Database**

The backend uses the **Neon tech PostgreSQL database**. Configuration details can be found in the `.env.samples` file.
